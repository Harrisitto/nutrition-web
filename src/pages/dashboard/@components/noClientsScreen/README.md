Esta pagina se renderiza cuando no se encuentra la información del usuario en la vista nutri_profile de supabase. Al confirmar se crea esa fila (o se actualiza el nombre si ya existe).
Es un prompt para poder insertar una fila con el nombre y poder trabajar desde ahí.

Se usa el componente del formulario para renderizar los campos con un estilo uniforme y constante a través de toda la aplicación.
